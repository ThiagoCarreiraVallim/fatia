# Arquivo morto

**Nada aqui descreve o estado atual do projeto.** São planos de execução escritos
antes de o trabalho acontecer, preservados como registro histórico de _como_ uma
mudança grande foi conduzida — não como especificação do que o sistema faz hoje.

Se você quer saber o que existe, o que está em andamento ou o que vem a seguir:

| Pergunta                           | Onde                                                                                                                             |
| ---------------------------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| O que está sendo trabalhado agora? | [Issues](https://github.com/ThiagoCarreiraVallim/fatia/issues) — organizadas em épicas, mapeadas em [`../TASKS.md`](../TASKS.md) |
| Como o sistema é desenhado?        | [`../ARCHITECTURE.md`](../ARCHITECTURE.md)                                                                                       |
| Por que ele é assim?               | [`../ADR/`](../ADR)                                                                                                              |
| O que é o produto?                 | [`../PRD.md`](../PRD.md)                                                                                                         |

## Conteúdo

- `plans/` — planos de fase escritos à mão (Fase 1 de nutrição, enriquecimento de
  exercícios, melhorias do app). Todos concluídos.
- `superpowers/` — planos e specs gerados por agente durante a refatoração modular
  do MCP e a fase F2a de treino. Escritos em inglês, com checkboxes de execução.
  Concluídos.

Estes arquivos citam caminhos, contagens e pendências que já não valem — por
exemplo `plan-fase1.md` fala em "~18 tools MCP", quando hoje são 87. Corrigi-los
seria reescrever a história; por isso ficam aqui, e não em `docs/`.
